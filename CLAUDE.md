# CLAUDE.md — Contexto do Projeto

## Empresa
*Chatfor* — Plataforma brasileira de Revenue Operations AI (RevOps AI).
Sede: São José dos Campos - SP.
Tese central: WhatsApp é o novo funil de vendas. IA é a força de trabalho invisível.
Missão: Democratizar IA comercial para PMEs no Brasil.

## Produtos
- *Chatfor Company:* Serviço contínuo de IA comercial — fee mensal R$6k–R$20k+
- *ChatforCRM:* Implementação de pré-vendas inteligente via WhatsApp — R$15.000
- *Chatfor Sales:* Success fee 20–35% sobre vendas geradas pela IA
- *ChatforSend:* Disparos em massa via API oficial do WhatsApp (em desenvolvimento)

## ICP (Cliente Ideal)
Dono de PME (Serviços, Infoproduto, Solar, Estética, Consórcio)
Fatura R$200k–R$500k/mês
Dor principal: "Sou refém do meu time comercial"
Desejo: "Quero acordar e ver que vendas aconteceram sem mim"
Mantra: "Reduzir time pela metade, vender o dobro"

## Diferenciais
1. Tecnologia proprietária (ChatforCRM)
2. IA que vende de verdade — 10% de conversão média sobre leads qualificados
3. Metodologia validada de prompt engineering
4. Alinhamento de incentivos (ganha quando o cliente ganha)
5. API oficial do WhatsApp (compliance Meta)
6. Visão de ecossistema (produtos + verticais + educação)
